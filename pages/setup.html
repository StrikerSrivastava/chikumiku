One-Time GitHub Setup
Create Your Two Repos

Repo 1 — Public (the app)

  1. Go to github.com/new → name it upsc-command-centre → Public → Create
  2. Upload the entire upsc-command-centre/ folder contents
  3. Go to repo Settings → Pages → Source: main branch → Save
  4. Your live URL: https://yourusername.github.io/upsc-command-centre

Repo 2 — Private (your notes)

  1. Go to github.com/new → name it upsc-notes → Private → check "Add README" → Create

Token

  1. Go to github.com/settings/tokens/new → Name: UPSC Notes → No expiration → Scope: repo only
  2. Generate → copy token → paste above → click Connect
